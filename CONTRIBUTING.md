# Contributing to PC Smart Utility

Thank you for helping improve PC Smart Utility.

## Before you contribute

1. Read the repository README.
2. Check existing Issues and Pull Requests before opening a duplicate.
3. Keep changes focused and explain why the change is needed.
4. Do not commit passwords, API keys, certificates, tokens, personal data, crash dumps, or build secrets.
5. Do not include proprietary Microsoft Store signing material.

## Pull requests

Please describe:

- What changed
- Why it changed
- How you tested it
- Any Windows versions or hardware affected
- Any screenshots or logs that help reproduce the issue

The OMIX STUDIOS maintainers review contributions before they become part of the official project.

## Licensing contributions

By submitting a contribution, you confirm that you have the right to submit it and that you agree to the project's contribution and licensing terms. OMIX STUDIOS may use accepted contributions in the project and in separately licensed commercial editions.

## Security

For security vulnerabilities, do not open a public issue. Follow SECURITY.md instead.

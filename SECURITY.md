# Security Policy

## Reporting a vulnerability

Please do not publish security vulnerabilities in a public GitHub issue.

Contact OMIX STUDIOS privately with:

- A description of the vulnerability
- Steps to reproduce
- Affected version
- Security impact
- Any proof-of-concept that is safe to share

Please do not include passwords, tokens, private keys, or personal information.

## Supported versions

The latest maintained release is the primary target for security fixes. Older versions may not receive fixes.

## Responsible disclosure

Please allow reasonable time for investigation and remediation before publicly disclosing a vulnerability.

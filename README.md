# PC Smart Utility 🛠️

**A Windows PC diagnostic, hardware, network, security, cleanup, and troubleshooting toolkit by OMIX STUDIOS.**

PC Smart Utility brings practical Windows maintenance and diagnostic tools into one desktop application.

- 🧹 PC cleanup / Auto-Clean
- 🔐 Cybersecurity learning and quiz content

## 🚀 Getting Started

### Requirements

- Windows
- Node.js
- npm

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm start
```

### Build Windows installer

```bash
npm run build
```

### Build AppX

```bash
npm run build-appx
```

### Build portable version

```bash
npm run build-portable
```
